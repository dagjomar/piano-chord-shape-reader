# Chord Shape Reader

Frontend practice tool for beginner and early-intermediate pianists learning to read **chord shapes** on the staff.

## Quick start

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — local development server
- `npm run build` — production build
- `npm test` — domain unit tests (Vitest)

## Docs

- [PRODUCT.md](./PRODUCT.md) — product vision, scope, and architecture
- [HANDOVER.md](./HANDOVER.md) — planning handover and milestones

## V1 status

- Flash-card chord shape practice (maj/min triads, inversions)
- VexFlow staff rendering with root accent
- Web MIDI + on-screen virtual piano
- Filter controls and localStorage persistence
